# 节流记账本 · 产品案例 01

产品经理作品集主站：以一篇完整 case study 为主体，界面稿作为附录，不以界面图堆砌代替产品判断。

**在线地址**：https://yqw43434-alt.github.io/pm-portfolio/

## 内容结构

| 章节 | 内容 |
| --- | --- |
| 01 背景与问题 | 为什么做、给谁用、问题定义 |
| 02 我的角色 | 独立完成的范围与技术形态 |
| 03 关键判断 | 四条决策，每条写清「备选 / 选择 / 代价」 |
| 04 方案与流程 | 从发额度到处理结余的闭环 + 4 张界面配图 |
| 05 结果与验证 | 已做到的、以及缺少大样本数据等短板 |
| 06 复盘 | 四个做错或做晚了的地方 |
| 07 附录 | 完整界面稿与 PDF 版 |

## 文件

| 路径 | 说明 |
| --- | --- |
| `index.html` | 主站，纯静态；无外部字体、脚本、统计依赖，可离线打开与打印 |

## 说明

- 界面元素为矢量重绘，非真机截图；画面内的金额、日期、账户名均为演示样例数据。
- 案例中的产品逻辑、业务口径与文案按线上小程序还原，未包含真实账本数据、AppID 或云环境信息。
- 作品集只保留一篇深度案例，不凑数量；数据边界在「结果与验证」一节如实说明。
